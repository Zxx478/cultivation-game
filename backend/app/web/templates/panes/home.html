荒天纪

一介荒村孤童，靠体质、加点、宗门或独行，把自己推向大帝之位。
十二境阶梯为骨，时间与寿元为刃——每点一次行动，世上便过去数日。

尚未有修行记录；点击「开始游戏」进入创角。

世界观

断槐村的老槐断了一半，另一半还活着。你是村里的孤童，先烧血，再谈仙。 世道将乱，六宗开山门，也有人选择不入山门、独行荒野。

核心循环

  • 微循环：选行动 → 耗时间 → 判定 → 得修为/资源 → 属性成长。
  • 中循环：境界圆满 → 筹备突破 → 成功进新境 → 解锁区域/功法/事件。
  • 宏循环：一世从锻血走到尽头，成帝、陨落或归隐，皆有结局。

时间与寿元（随境界动态增长）

1 年 = 360 日，1 月 = 30 日。行动耗时随大境提升而变长，越高境越接近“百年一闭关”。

三条路径

  • 宗门：辟府后择门，得方向树、宗门任务与独门功法。
  • 方向：剑 / 法 / 丹 / 阵 / 体五系，各三层节点，以贡献点亮。
  • 散修：无门无派，无方向加成，靠奇遇与禁地补强度。

存档选择

自动槽由系统在每次行动后书写；手动槽共三处，可读取、导出、导入。

    操作提示

    • 底部五Tab：洞府 / 修炼 / 背包 / 任务 / 更多。
    • 事件弹窗可用 1–4 选择，Esc 关闭。
    • 战斗中普攻/术法/防御/道具/逃跑；30 回合未分胜负则各自退开。
    • 刷新页面会从服务端快照恢复，不会重掷随机。
