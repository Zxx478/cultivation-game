# 《荒天纪》Web UI 设计规范（MVP）

> 依据：需求文档 §8.1 / §8.3 / §8.4。工程实现：Jinja2 首屏 + 原生 ES Module + CSS，无 npm、无 CDN、无外链字体。
> 目标：暗色水墨气质的桌面/移动双端界面，信息密度高但不拥挤，交互反馈明确。

---

## 1. 视觉基调

| 项 | 值 | 用途 |

| 墨底 | `#14120F` | 页面背景 |
| 墨底二 | `#1C1A17` | 卡片/面板 |
| 墨底三 | `#242019` | 悬浮/输入 |
| 纸色 | `#EFE6D6` | 主文字 |
| 纸色次 | `#BFB3A0` | 次要文字 |
| 纸色弱 | `#8A7E6C` | 辅助/禁用 |

| 青碧 | `#3E7C6B` | 灵力/成功/治疗 |
| 鎏金 | `#C9A227` | 突破/稀有/强调 |
| 边框 | `rgba(201,162,39,0.18)` | 1px 描边 |
| 阴影 | `0 8px 32px rgba(0,0,0,0.45)` | 浮层 |

- **双主题**：默认「夜色」（上表）；提供「宣纸」主题（背景 `#F3EDE1`、文字 `#1C1A17`、卡片 `#FBF6EC`），用 `data-theme="paper"` 切换，选择存 `localStorage`（仅 UI 偏好，合规）。
- **质感**：用 CSS 重复线性渐变模拟宣纸纤维/墨晕，不引用外部图片。
- **字体**：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", serif`；数字/属性用 `"Noto Sans SC", "Microsoft YaHei", sans-serif`。不加载外链字体，系统字体回退。
- **禁止**：emoji、颜文字、霓虹渐变、圆角大于 8px 的卡片、纯黑 `#000` 背景。

## 2. 布局

### 桌面（≥1024px）
```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：道号 / 境界 / 第 N 年 / 剩余 M 年 / 灵石 / 主题 / 存档   │
├────────────┬─────────────────────────────────┬───────────────┤
│ 左侧栏      │ 主内容区（当前 pane）             │ 右栏（日志）   │
│ 224px      │ minmax(0,1fr)                    │ 300px         │
│ 角色卡      │ 修为条 + 行动按钮 + 面板           │ 事件流/里程碑  │
│ 导航 12 项  │                                 │               │
└────────────┴─────────────────────────────────┴───────────────┘
```
- 左侧栏固定，`position: sticky; top: 0; height: 100vh`；导航项为竖排文字 + 细线，当前项左侧 2px 朱砂竖线。
- 右栏日志可折叠；≤1280px 隐藏为抽屉。
- 主内容区最大宽度 1180px，居中。

### 移动（≤768px）
- 顶栏压缩为两行：身份 + 资源；修为条常驻。
- 底部 Tab 五宫格：洞府 / 修炼 / 背包 / 任务 / 更多（其余面板从「更多」抽屉进入）。
- 弹窗全屏化；战斗界面占满视口，操作按钮固定在底部。
- 字号下限 14px；点击目标 ≥ 44×44px。

## 3. 组件

### 3.1 状态条
- 修为条：高 10px，底色 `#2A241C`，填充鎏金→朱砂渐变；右侧文字「本级 62.4%」；升级时条闪一次金光。
- 气血条：朱砂；灵力条：青碧；寿元条：纸色，<20% 转朱砂并 `animation: pulse 2.4s infinite`（`prefers-reduced-motion` 时关闭）。
- 条内不写数值，数值放条右侧，等宽数字。

### 3.2 卡片
- 背景 `#1C1A17`，1px 金边，内边距 16–20px；标题 18px 宋体，左上角一枚 2px 朱砂短横。
- hover：边框透明度 0.18 → 0.35，`transform: translateY(-1px)`，120ms。

### 3.3 按钮
- 主行动：朱砂底、纸色字、直角 2px 圆角；hover 提亮 8%；disabled 降饱和 60%。
- 次行动：透明底 + 金边；危险操作：朱砂文字 + 朱砂边。
- 所有按钮带 `:focus-visible` 2px 鎏金描边。

### 3.4 表格 / 列表
- 表头 13px 弱色，行高 40px；斑马纹用 `rgba(239,230,214,0.03)`；数字右对齐。
- 功法/装备条目：左侧品阶色条（凡灰/灵青/宝蓝/圣紫/帝金），名称 + 类型 + 层数；右侧操作。

### 3.5 弹窗
- 事件弹窗：宽 640px，顶部标题 22px，正文 16px/2.0，选项纵向排列；选项含风险标签（「危险」「消耗」「因果」），不显示具体成功率。
- 突破弹窗：成功率明细表 + 最终成功率大字 + 惩罚预告；「开始突破」朱砂主按钮。
- 战斗：全屏 overlay，上方双方血条/灵力条，中部战报滚动区，下方 5 个行动按钮；伤害飘字绝对定位，暴击鎏金描边，闪避显示「闪」。
- 关闭：右上角「×」；`Esc` 关闭；事件/突破不可点遮罩关闭。

### 3.6 Toast / 日志
- Toast 右下角，3 秒消失；成功青碧左边线，失败朱砂左边线；文案必须可执行（含缺口数值）。
- 右栏日志按时间倒序，最多 50 条；里程碑用鎏金小圆点。

## 5. 交互规则（必须实现）

1. 所有写操作按钮点击后立即 `disabled` + 文案变「结算中…」，响应后恢复，防双击。
2. 修为条变化用 400ms 插值；数字用 600ms 计数动画；`prefers-reduced-motion` 时直接赋值。
3. 待决事件或战斗存在时，行动按钮组整体禁用，并提示「先处理眼前之事」。
4. 刷新页面：`GET /state` 恢复；若 `pending_event`/`combat.status=active`，自动重新打开对应弹窗/战斗。
5. 409 版本冲突：弹 Toast「存档已在别处变更」+ 提供「重新载入」按钮，不自动覆盖。
6. 错误文案必须含具体缺口，例如「灵石不足（需 5,000，现有 1,200）」。
7. 角色名等用户输入一律 `textContent` 渲染；禁止 `innerHTML` 拼接。
8. 键盘：`1/2/3/4` 选事件选项，`Esc` 关闭弹窗，`Space` 继续；输入框聚焦时不拦截。
9. 主题切换、动效开关存 `localStorage` 的 `ui.prefs`，不存任何角色数据。
10. 首屏无外域请求；所有资源本地相对路径。
