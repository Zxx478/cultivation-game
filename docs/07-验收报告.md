## 2. 端到端人工验证（Playwright，1440×900 与 375×812）

已实测链路：

0. 首页：标题/玩法说明/耗时表（基础 30、辟府当前 42）/开始游戏/存档选择/继续修行。
1. 创角：重掷 → 姓名/性别/性格 → 加点 5（单项 ≤3）→ 二次确认 → 入世。
2. 洞府：闭关（修为/年龄/寿元刷新）→ 事件弹窗（选项/结果/Toast）。
3. 任务：`断槐之下` 领取 → 状态转 completed → 解锁下一任务。
4. 突破：Lv.9 满修为 → 冲关弹窗（成功率明细/惩罚预告）→ 开始突破 → Lv.10、寿元 100→150 年。
5. 宗门：Lv.10 入宗（青云剑宗，试剑连胜 3）→ 定方向（剑修）→ 接/交宗门任务 → 贡献到账。
6. 战斗：地图前往村后山 → 历练 → 战斗弹窗（普攻/术法/防御/道具/逃跑）→ 胜利结算。
7. 存档：手动槽保存/读取；导出文本可粘贴回导。
8. 响应式：375px 无横向滚动，底部五 Tab 可用；控制台 0 error、0 外域请求。

## 4. 已知缺口（不影响交付，列入后续）

1. `techniques/learn` 未与「功法解锁标记」打通，可学习任意已配置功法（经济向，非安全）。
2. 方向节点仅应用「全属性%/暴击/先手/普攻/灵力上限」类效果；控制/免死/技能类未接入战斗。
3. 事件文案偏短（最长 60 字），未达 200 字上限的内容密度。
4. 结局只有 `dead`/坐化置位，无道途志与轮回继承。
5. 卷三 15 任务、剩余 8 处禁地未开放（配置已在，`enabled=false`）。
