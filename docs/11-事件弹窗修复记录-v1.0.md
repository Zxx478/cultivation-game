# 事件弹窗修复记录 v1.0

> 触发问题：活动（奇遇）第一个交互页面无法点击关闭；页面内属性加成显示为英文。
> 修复范围：`panes/event` 关闭交互、事件效果文案中文化、`attr: mnd` 落地。
> 验证基线：`pytest backend/tests -q` → **155 passed**；浏览器端到端断言 **19/19 通过**（`tools/verify_event_ui.py`）。
> 提交原则：每条修复独立 commit，消息含时间/内容/操作人。

---

## 1. 现象与结论

| 反馈 | 结论 | 严重度 |
|---|---|---|
| 第一交互页面无法关闭（点关闭无效） | 「继续」按钮**从未绑定 click**；「×」根本不存在；Esc 收起后又被状态同步强行弹回 | P0 |
| 属性加成显示英文 | 效果字典以引擎键名（`attr` / `items_gained` / `hp_pct` / `luk` / `chance_bp`）直接渲染，未做中文映射 | P1 |
| （连带）道心加减不生效 | `attr: mnd` 写到了角色表不存在的 `mnd` 列，被白名单静默丢弃 | P1 |
| （连带）道心显示为 `mnd` | 角色页基础属性缺 `mnd` 标签，直接显示内部键名 | P2 |
| （连带）选项按钮结算后被压成竖排 | `withBusy()` 用 `textContent` 覆盖再写回，摧毁了按钮内部结构 | P1 |

---

## 2. 根因拆解（关闭失效）

1. **模板里没有关闭按钮**：`templates/panes/event.html` 只有隐藏的「继续」，没有 `×`。
2. **「继续」从未绑定事件**：`panes/event.js` 的 `#event-continue` 监听只写在 `export default { enter() }` 里；而事件层**不是路由**（`core/router.js` 的 `ROUTES` 无 `event`，注释亦写明浮层「不占路由」），外壳只调 `eventPane.open()`，`enter()` 永远不会执行 → 按钮是死元素。
   - 同类问题此前已在突破/战斗层修过（在 `open()` 里绑定），事件层漏改。
3. **收起后立刻被弹回**：`core/app.js` 的 `syncOverlays()` 只要 `view.pendingEvent` 为真且浮层关闭就重新 `open()`；Esc 走 `closeLayer()` 后 `pendingEvent` 仍在，任何一次 `game:sync`（行动、存读档、结算后刷新都会派发）就把它弹回，表现为「关不掉」。
4. **无选项分支死循环**：`renderChoices()` 在 `choices.length === 0` 时提前亮出「继续」，点它只刷新 `/state`，事件仍 pending → 再次弹回。
5. **`withBusy` 破坏结构**：结算时 `button.textContent = '推演…'` 抹掉 `.choice__key/.choice__label/.choice__tags`，`finally` 里再写回纯文本，按钮变成一整串文字挤进 28px 首列 → 竖排。

## 3. 修复内容

### 3.1 关闭交互（前端）

| 改动 | 文件 | 说明 |
|---|---|---|
| 新增 `×` 关闭按钮 | `templates/panes/event.html` | `#event-close`，复用 `.layer__head .iconbtn` 定位 |
| 绑定迁到 `open()` | `panes/event.js` | `bindControls()` 在每次 `open()` 时幂等绑定 `×` 与「继续」，不依赖 `enter()` |
| 新增 `dismiss()` | `panes/event.js` | 未结算＝「暂时收起」并记下 `dismissedId`；已结算＝收起后刷新 `/state` |
| 外壳不再强行弹回 | `core/app.js` | `syncOverlays()` 增加 `eventPane.isDismissed()` 判定；Esc 改走 `eventPane.dismiss()` |
| 常驻「续」入口 | `core/app.js` + `main.css` | 收起后底部浮出「一桩因果未了 · 继续」，点击可回到同一桩事；浮层打开时自动隐藏 |
| 兜底 | `panes/event.js` | 无选项/未结算时点「继续」只收起，不进入「刷新→弹回」死循环 |

### 3.2 效果行中文化（后端 + 前端）

| 改动 | 文件 | 说明 |
|---|---|---|
| 新增翻译器 | `services/effect_lines.py` | `EffectOutcome` 字典 → `[{label,text,tone}]`；属性/状态/物品/功法按内容表取中文名；`chance_bp`/`success`/`flags` 一律不展示（设计 §3.5） |
| 回包补字段 | `services/story_event_service.py` | `choose()` 增加 `effect_lines`，`deltas` 原样保留（向后兼容） |
| 前端中文映射 | `core/actions.js` | `effectLines()` 重写：十项属性、状态、物品、功法、耗时全部中文化；未知英文键不再外泄 |
| 渲染入口 | `core/actions.js` | 新增 `renderDeltaLines()`；`renderDeltas()` 复用 |
| 取值修正 | `panes/event.js` | 优先 `effect_lines`，其次 `deltas.effects`（原先取整个 `deltas`，把 `success`/`chance_bp` 一起渲染出来） |

### 3.3 连带修复

| 改动 | 文件 | 说明 |
|---|---|---|
| `attr: mnd` 落地 | `services/story_event_service.py` | 新增 `_ATTR_COLUMNS = {"mnd": "dao_heart"}` 与上下限夹取；白名单外的列不再静默丢写 |
| 角色页 `mnd` 标签 | `panes/character.js` | `BASIC_LABELS` / `TIPS` 补 `mnd: 道心` |
| `withBusy` 保结构 | `core/ui.js` | 改为「摘下子节点 → 挂占位 → 原样挂回」，不再用 `textContent` 覆盖 |
| 占位跨列 | `main.css` | `.choice .btn__busy { grid-column: 1 / -1; }`，避免结算文字被挤成竖排 |
